# 超額報酬同時以「分析池」與「全市場」兩種基準儲存

`verdict_detail.excess` 原本只有一種定義：該檔前瞻報酬減去**同一分析日、分析池全體**的平均報酬。
這個基準把市場 beta 構造性移除，量的是純選股力——但它會隨 universe 定義漂移。
2026-08-15 加入流動性下限後，分析池由 2,077 檔降為 1,310 檔（排除 664 檔近 20 日中位量
<100 張、105 檔無價格資料），**基準本身就移動了**，換前的 +2.18% 與換後的數字減的不是同一個東西。
而 `NFR-QUAL-001` 的兩個門檻都建立在這個基準上。

決定：**雙軌並存**。`excess_pool` 保留現行語意；新增 `excess_mkt`，相對全市場等權日報酬計算。

## Considered Options

- **(a) 維持單一「分析池」基準。** 語意最乾淨，但只要 universe 變動就跨期不可比，
  而 universe 已經變動過一次，未來加入上櫃／興櫃還會再變。
- **(b) 改用單一固定市場基準（0050 或全市場等權）。** 可跨期比較，但把擇時混進來：
  空頭時全部標的皆為負超額、多頭時皆為正，判斷力訊號會被市場方向淹沒。
- **(c) 雙軌並存（採用）。**

## Consequences

- 兩個量回答不同問題，兩者都需要：`excess_pool` 回答「在同一天的候選裡這個判斷有沒有挑對」；
  `excess_mkt` 回答「這個判斷跨期而言值不值得執行」。
- 歷史資料可重算：`stock_price` 齊全，回填 `excess_mkt` 不需重跑任何 LLM。

  因為池子定義變了。~~
  **已由 [ADR-0004](0004-分析層與執行層分離.md) 解除**：分析池的邊界改由「輸入資料是否足以
  計算因子」決定，不再隨部位規模或效能考量變動，`excess_pool` 的基準因此穩定。
  僅 2026-08-15 當晚套用過流動性下限的那一段需標註，不需長期維護兩套基準。
