# 價值角色改用規則模板

本決定以正式機 `172.16.9.166` 為準。延續 2026-10 風險管理與籌碼角色改規則模板的做法（`src/moe/rule_roles.py`）。

## 現況量測

**立場幾乎是程式算好的數字。** 價值角色輸入的 `valuation.composite.verdict`（例如「嚴重高估」）已由程式算出；在 232 筆可取得現價與合理價的歷史報告中，LLM 立場與「現價／合理價」比值的 Spearman 相關係數為 0.91。

**立場對報酬沒有正向資訊。** 2026-06-19 至 09-15 的 20 日超額報酬（約 2 萬筆）：立場「嚴重高估」平均 +1.15%、「合理」平均 -1.14%，「合理」減「嚴重高估」的價差 -2.29pp（日期分群 bootstrap 95% 區間 -3.92 至 -0.45，69 個日期，單一多頭期樣本）。

**影子測試（2026-10-21，`scripts/rule_roles_shadow.py`，48 檔、每種編制各跑一次）。** 編制定義（當時）：P＝價值走 LLM、風控與籌碼用模板（當時的現行）；P2＝與 P 完全相同再跑一次；F＝六角色全走 LLM；V＝價值、風控、籌碼都用模板（本決定的新預設）。

| 比較 | 最後裁決一致 | 買進賣出對翻 |
|---|---|---:|
| P↔P2（同編制再跑一次，雜訊底線） | 39/48 = 81%（Wilson 95% 68～90%） | 0 |
| V↔P（價值改模板 vs 價值走 LLM） | 42/48 = 88%（75～94%） | 0 |
| P↔F（風控與籌碼模板 vs 六角色全 LLM） | 32/48 = 67%（53～78%） | 1 |

P 與 P2 本來就一致的 39 檔中，V 與它們相同的有 35 檔（90%），F 只有 29 檔（74%）。每檔耗時中位數：P 93 秒、V 83 秒，模板比 LLM 版快約 11%（48 檔總耗時 76 分鐘對 70 分鐘）。

## 決定

**價值角色預設改用規則模板（`rule_roles.DEFAULT_RULE_ROLES` 加入 `value-analyst`）。**

- 價值角色的裁決差異落在重跑雜訊內，沒有買進賣出對翻，且省下一次 LLM 呼叫。
- 這是「不比現行差」的決定，不是「比較準」的證據：樣本只有 48 檔、單一天，也沒有後續績效可比。
- 風險管理與籌碼維持規則模板。六角色全 LLM 與 P 的差異較大（一致率 67%，穩定集 74%），但區間仍與雜訊底線重疊，且一致率只反映裁決是否改變、不反映誰比較準，所以不據此改回 LLM。

## 還原方式與重新評估

- 只讓價值角色回到 LLM：`TEAM_RULE_ROLES=risk-manager,chip-analyst`；全部回到 LLM：`TEAM_RULE_ROLES=`。
- 這批 48 檔約 2026-11-18 之後有 20 日報酬，屆時可再看各編制的買進／賣出後續表現；樣本偏小，只當線索。
- 若日後找到「價值立場」帶來報酬資訊的證據，再重新評估是否讓 LLM 回來。
