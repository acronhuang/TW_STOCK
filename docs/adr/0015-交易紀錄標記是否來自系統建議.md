# 交易紀錄以一個布林值標記「是否因系統建議而做」，歷史資料以自動比對回填

[ADR-0014](0014-系統成功的判準.md) 把「決策支援價值」列為輔助判準：
量測「系統判買進且實際買進」的標的，事後表現是否優於「自己找的」標的。
但 `portfolio_trades` 的欄位是 `action / price / shares / cost / commission / total / note / date`，
**沒有任何欄位連結到當時的建議**。

目前只能以「這檔股票曾經被判過買進」粗略比對，而那太雜訊：系統對 574 檔給過買進判斷，
分散在不同時間點；持倉中 8 檔「曾被判買進」，但可能是先買了、系統三個月後才判買進，
也可能是因系統建議而買、但當時定案是「持有」而非「買進」。

決定：
1. **新交易**：`portfolio_trades` 增加布林欄位 `from_system`（是否因系統建議而做）。
2. **歷史 17 筆**：以「交易日前 N 天內是否有該檔的買進定案」自動比對後**人工複核**回填，
   讓輔助判準立刻有基準線。此法僅作為回填手段，不作為長期方案。

## Considered Options

- **(a) 記錄建議 ID**（`source_verdict` 或 `team_analysis._id`）。最精確，
  但每筆交易多一個查詢動作。`portfolio_trades` 已停更四個月，
  **在一個已停更的紀錄上增加負擔，等於保證它繼續停更**。
- **(b) 純事後自動比對。** 不需額外記錄，但「N 天內」是猜的數字，
  且無法分辨「看到建議才買」與「剛好同時想買」。
- **(c) 一個布林值（採用）。** 最低持續成本，且足以支撐核心問題——
  「系統推薦的那些，表現有沒有比我自己找的好」——只是失去「是哪一次建議」的細節。

## 前提（2026-08-16 已確認）

`portfolio_trades` 最後一筆為 2026-04-15，停更四個月。經確認**將恢復維護**，
本 ADR 與 [ADR-0014](0014-系統成功的判準.md) 的輔助判準因此成立，
系統的成功判準為雙軌：判斷品質 + 決策支援價值。

若日後該紀錄再度停更，應主動撤回輔助判準而非讓它掛著——
依 [ADR-0002](0002-檢查的有效性條件.md) 第 1 條，一條無法被檢查的需求不該存在。
