# 不訂閱 FinMind 付費方案

本決定以正式機 `172.16.9.166` 為準。脈絡、量測與替代方案見 OpenSpec 變更 `openspec/changes/archive/2026-10-21-evaluate-finmind-sponsor/`（[design.md](../../openspec/changes/archive/2026-10-21-evaluate-finmind-sponsor/design.md)）。

## 現況量測

| 項目 | 結果 |
|---|---|
| 免費額度 | 每小時 600 次，滾動 60 分鐘（2026-10-21 每分鐘取樣跨整點，00:00 沒有歸零） |
| 402 的來源 | 每晚 01:00 `sync_dividend_detail.py --limit 600` 把額度用光，加上每小時下載約 300 次，01:05 起被擋；不是額度太小 |
| 修正（`--limit 250`，2026-10-13） | 自 10-14 起連續 7 天 `check_finmind_quota.py` 通過，每晚 01:05 開始時用量 552/600 |
| 每小時重抓三個基本面資料集 | 2026-10-13 至 10-20 共 181 份快照、約 168 萬次文件接觸，內容變動 0 筆 |

## 決定

**不訂閱 Sponsor 與 Sponsor Pro，也不為了「可能有用」而買資料。**

- 唯一可見的額度問題是我們自己的排程造成，已用降低每日股利同步上限解決。
- 價量、法人、融資的整市場資料已由官方按日期端點免費取得。
- 付費方案多出的資料（分點、八大行庫、融資維持率、分 K、逐筆）沒有任何需求，也沒有寫成可執行的檢查（ADR-0001：沒有可執行的檢查就不算需求）。

## 重新評估條件

任一成立才重新評估：

1. 上述修正之後，每週仍有 HTTP 402（`check_finmind_quota.py` 未通過）。
2. 出現已寫成可執行檢查的整市場交叉核對需求。
3. 出現分點等付費資料的需求，且有可執行的檢查。

條件成立時另開變更，只訂閱 1 個月 Backer：先核對官方價格與授權條款，完成整市場交叉核對與缺口補寫並輸出報告，期滿不續訂。

## 後續

每小時下載對三個基本面資料集的重抓沒有產出，已於 2026-10-21 改為每日一次（`src/ops/daily_gate.py`，預設 03:00 之後的第一輪、成功才記帳、失敗下一小時重試），每天省約 7,200 次請求。量測期間不含月營收公告期，11 月初第一個公告期要確認月營收仍在公告日當天或隔天進來。
