# 接受「總經角色產業共用」帶來的同質化風險，不另做量測

2026-08-15 將總經角色改為以產業為鍵快取：同產業第二檔起不再呼叫 LLM，
直接重用該產業第一檔的報告並替換股名。實測快取命中 230 次／實算 18 次，
**一份總經報告平均被 13.8 檔共用**，省下約 19.8% 的 LLM 時間。

依據是總經角色的提示詞**完全不含個股資料**——只有第一行帶股號股名，
其餘 100% 為市場層級（利率／匯率／CPI／貨幣供給），它本來就做不出個股分析。

未量測的風險：顧問整合讀六份角色報告，其中一份現在對同產業所有標的逐字相同；
合議委員再對該草案投票。**同產業的合議定案是否因此變得更一致，沒有任何測量檢查過。**
若變得更一致，後果是投組的隱性集中——看似獨立評估了 20 檔電子股，
實際上它們共享六分之一的輸入。

決定：**接受此風險，不另做量測。** 省下的 19.8% 值得，且同產業本來就應有相關性。

## Consequences

- 這是一個**知情而接受的風險**，不是「已驗證無虞」。部署該優化時只驗證了
  「省多少時間」與「股名是否正確替換」，未問「它會不會讓分析變得更同質」——
  而那是此優化唯一真正的風險。此處明文記錄，以免日後被誤讀為已驗證。
- 若日後需要重新評估，**成本很低且不需重跑 LLM**：2026-08-07 那批（2,077 檔、無快取）
  與 2026-08-14 之後（有快取）的定案皆在 `team_analysis` 中，
  直接比較「同產業內定案的最多數佔比」即可，快取前的實測值可作為門檻的依據。
- 隨時可關閉：`TEAM_MACRO_CACHE=0` 還原為每檔重算。
