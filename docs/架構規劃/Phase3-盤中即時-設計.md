# Phase 3 盤中即時決策支持 — 設計文件(不實作,待核准)

> Phase 1 每日選股合議 ✅、Phase 2 持倉風控合議 ✅ 已上線。Phase 3 補「盤中(09:00–13:30)即時」這一段。
> 本文只做設計與可行性分析,經核准後才排實作。

## 1. 目標與範圍
盤中要服務的決策只有兩個,**不做即時當沖選股**(那是另一個風險等級):
- **A. 持倉即時風控**:手上部位盤中觸及停損/急殺/爆量出貨 → 即時提醒「該不該砍」。
- **B. 觀察名單進場觸發**:當日選股 picks / 波段觀察股,盤中觸及預設進場條件(突破/回測支撐/量增)→ 提醒「可進場」。

明確**不做**:高頻/逐筆當沖訊號、盤中即時擂 LLM 合議(延遲高、成本高、LINE 額度不夠)。

## 2. 關鍵前提:盤中資料源(目前缺,是最大工項)
現況最細只到**每小時 FinMind**(收盤性質資料),**無真正即時報價**。可行來源:

| 來源 | 延遲 | 成本 | 評估 |
|------|------|------|------|
| **TWSE MIS**(`mis.twse.com.tw/stock/api/getStockInfo.jsp`) | ~5–20 秒快照 | 免費 | ✅ **推薦 MVP**。免費、涵蓋上市+上櫃、量價五檔齊全;但無官方 SLA、需節流與容錯 |
| FinMind 分鐘K(`TaiwanStockPriceMinute`) | 分鐘、常延遲 | 部分需付費 | 備援,不即時 |
| 券商 API(shioaji/fugle) | 逐筆即時 | 需開戶+串接 | 過度,MVP 不需要 |

→ **需新建輕量 collector**:`scripts/intraday_snapshot.py`,盤中每 N 分鐘打 TWSE MIS 抓「持倉+觀察名單」這一小撮(非全市場,約 30–60 檔)現價/量,寫入新集合 `intraday_quotes`(當日 TTL)。只抓需要的標的 → 對 MIS 友善、不會被擋。

## 3. 三類盤中訊號(規則觸發,非 LLM)
盤中用**確定性規則**即時判斷,便宜可靠:
- **持倉**:現價 ≤ 成本×(1−停損%)、現價較開盤急殺 >X%、爆量(量 > 均量×K)且價跌 → 風控警示。
- **觀察名單**:現價突破前高/型態頸線、回測支撐不破+量縮、當日漲幅+爆量 → 進場提示。
- **大盤**:加權指數急殺 >X%、成交量異常 → 全局風險旗標(附加在個股訊號上)。

門檻沿用 Phase 2 已定的停損/風報比參數,單一真相仍是 `portfolio_positions`。

## 4. 架構(接既有 pipeline,production 級)
```
盤中排程(cron, 09:05–13:30 每 15 分)
  └─ intraday_snapshot.py         抓 MIS → intraday_quotes
       └─ intraday_rules.py       規則引擎 → 產生 triggers(去重:同標的同類型當日一次)
            ├─ 命中「重大」(停損/爆量出貨) → 選擇性呼叫 Phase2 risk_deliberation 做「單檔快速合議」(只對命中檔,不是全持倉)
            └─ 交付層(見 §5)
```
- **不即時擂全 MoE**:只有「重大命中」才對**單一檔**觸發 Phase 2 既有合議(續抱/減碼/出場),控成本與延遲。
- 複用既有:`portfolio_positions`、`risk_deliberation.py`、`_load_positions()`、consensus。

## 5. 交付通道(LINE 已爆額 → 必須改設計)
LINE 月額度已用盡(429),**盤中不能靠 LINE 狂推**。優先序:
1. **Dashboard 即時頁**(推薦):新 `dashboard/pages/intraday.py`,盤中自動刷新,紅/綠燈列出命中訊號+Phase2 合議。零額度成本。
2. **盤中 spool + 收盤彙整**:沿用既有 `LINE_SPOOL`+`evening_digest` 機制,盤中訊號寫 spool,**只有「重大即時」才即時推 1 則**,其餘併入收盤 digest。呼應既有降噪成果。
3. (未來)LINE 額度解決後再開即時推播。

## 6. 頻率與節流
- 頻率:每 15 分(MVP)。急殺可縮到 5 分,但先驗證 MIS 穩定度。
- 去重:同標的同訊號類型當日只推一次;狀態檔 `logs/.intraday_trigger_state`(仿 hourly_notify 節流)。
- 盤後:自動關閉(13:35 後不跑),清當日 intraday_quotes。

## 7. 風險與限制
- **MIS 無 SLA**:需容錯(逾時跳過、連續失敗告警),不可因抓不到就靜默沿用舊價(踩過 [[stale-data-silent-reuse]])。
- **~20 秒延遲**:定位為「風控輔助」非「搶單」,文案要講清楚不是逐筆即時。
- **回填/自我驗證**:盤中訊號需標時間戳,避免長對話捏造(見 [[self-confabulation-long-sessions]])。
- **LINE 額度**:MVP 以 dashboard 為主,不加重 LINE 負擔。

## 8. 建議 MVP 分期
- **M1(最小可用)**:intraday_snapshot(MIS,持倉+picks)+ 規則引擎持倉停損/爆量 + dashboard 即時頁。**不接 LLM**。→ 先證明資料源與規則可靠。
- **M2**:加觀察名單進場觸發 + 重大命中觸發單檔 Phase2 合議 + spool 併收盤。
- **M3**:大盤旗標、5 分鐘急殺模式、(若 LINE 解額)即時推播。
