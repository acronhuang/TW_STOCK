# v3 假設 — 純品質(ROE)tilt(證據驅動)

> 方法論同 v1:報告→選型→TDD→E2E。差別:**先用真實資料做選型**,不再盲猜啟發式。

## 0. 為何從 v2 轉向 v3(證據)
v2(追高 AND 價值/品質差)實測 Δ均超額 **−0.08%**、僅降級 122/2162 → 無效。
分位分析(真實 2162 筆買進,前瞻 20 日超額)揭露**單一乾淨訊號**:

| 分位 | PE(價值) | prior(動能) | **ROE(品質)** |
|---|--:|--:|--:|
| Q1(低) | +0.59% | +0.91% | **−0.99% / 35.8%** |
| Q4(高) | +1.38% | −0.27% | **+0.57% / 48.8%** |

- **PE 非單調(U 型)** → value tilt 會錯(貴的 Q4 反而最好)。
- **動能**只有 Q1(最低)好,Q2–4 皆差 → 弱訊號。
- **ROE 單調**:低→高 命中 35.8%→48.8%、超額 −0.99%→+0.57% → **最強、最乾淨**。

## 2. 選型(依證據)
- **v3a 純 value(PE)tilt** — ❌ 資料否決(PE U 型,貴的反而好)
- **v3b 純 momentum tilt** — ⚠️ 僅最低分位有效,弱
- **v3c 純 quality(ROE)tilt** ⭐ — 單調最強;規則:**ROE 百分位 < 25(底四分位)→ 降級持有**

**預估效果**(以分位推算):移除底四分位 ROE 後,v3 均超額 ≈ **+0.17%**(v1 −0.03%)、命中 ≈ **44.1%**(v1 42.3%)→ Δ命中 **+1.8pp**、Δ超額 **+0.20%**。**方向為正**(v2 是負),但仍未達 NFR 門檻(55%/+1.47%)。

## 3. 最沒把握的 3 件事(v3)
1. **仍遠低於 NFR 門檻** —— 品質 tilt 只把買方從「無 alpha」推到「微正」,離 55%/+1.47% 還很遠。可能買方問題根深(選股訊號本身),單一 tilt 不夠。
2. **in-sample / 單一空頭區間** —— ROE 單調性可能是此區間特性;多頭時高 ROE 未必續強(品質因子有 regime)。
3. **ROE 覆蓋與時效** —— 小型股 ROE 稀疏/過期,底四分位判定可能誤傷或漏判;影子模式對這批退化成維持原判。

## 切換準則(不變)
影子驗證 → out-of-sample + 多區間穩健 → 團隊審 → 才升級 live。v3 即使 in-sample 改善,**未達門檻前不切**。
