## 3. 失效降級路徑（可靠性關鍵 — fail-open）
```mermaid
flowchart LR
  A[外部呼叫] --> B{RSS 例外?}

  B -- 否 --> D{Ollama 逾時/連線失敗?}
```

## 5. 時序圖 — 一次「國際新聞分析」的完整呼叫順序
```mermaid
sequenceDiagram
    autonumber
    actor User as 使用者
    participant UI as rag_page.show()
    participant WS as web_search
    participant GN as Google News RSS
    participant IN as international_news
    participant OL as Ollama (qwen2.5-14b)

    User->>UI: 輸入問題 q、選事件類型 event_type、來源模式 news_mode
    User->>UI: 按下「分析外部新聞」
    alt q 為空
        UI-->>User: ⚠️ 「請先輸入問題」(不呼叫外部)
    else q 有值
        UI->>WS: search_news_by_mode(f"{q} {event_type}", news_mode)
        loop 每個地區 region
            WS->>GN: GET /rss/search?q,hl,gl,ceid (timeout=6s)
            alt RSS 成功
                GN-->>WS: RSS XML
                WS->>WS: regex 解析 + 去重(by url)
            else RequestException
                GN--xWS: 逾時/錯誤
                WS->>WS: fail-open → 該地區回 []
            end
        end
        WS-->>UI: grouped_results {來源標籤: [articles]}
        UI->>UI: 攤平為 international_results

        UI->>IN: generate_analysis(q, event_type, articles)
        alt articles 為空
            IN-->>UI: 「沒有可用外部證據」, elapsed=0 (不呼叫模型)
        else 有證據
            IN->>IN: build_prompt(僅含外部 RSS 標題/連結 + SYSTEM 六條約束)
            IN->>OL: POST /api/generate (timeout=120s, temp=0.1)
            alt Ollama 正常
                OL-->>IN: 分析文字(四節: 影響/產業/台股標的/風險)
                IN-->>UI: (analysis, elapsed)
            else 逾時/連線失敗
                OL--xIN: Exception
                IN--xUI: 例外向上拋
                UI->>UI: catch → analysis="國際新聞分析失敗:err", elapsed=0
            end
        end

        UI-->>User: 顯示「國際新聞分析」+ 免責「不是投資建議」
        UI-->>User: 顯示外部證據清單 [1]..[n]（分來源群組）
        UI-->>User: 下方仍呈現本機檢索段落（不受外部影響）
    end
```

### 時序圖關鍵契約
| 步驟 | 契約 | 對應測試/文件 |
|---|---|---|
| 空問題保護 | 未輸入 q → 提醒且不外呼 | E2E `test_empty_question_guard` |
| RSS fail-open | 單一地區失敗回 `[]`，不中斷其他地區 | `test_google_news_search_fails_open_on_request_error` |
| 去重 | 相同 url 只留第一筆 | `test_google_news_search_deduplicates_by_url` |
| 證據受限 | prompt 僅含外部標題，禁用內部資料 | `test_build_prompt_limits_analysis_to_external_evidence` |
| 空證據守衛 | 無 articles → 不呼叫模型 | `generate_analysis` 前置判斷 |
| Ollama 降級 | 逾時/失敗 → 顯示失敗訊息，本機結果不受影響 | 失效降級路徑（圖 3） |
