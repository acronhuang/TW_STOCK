# 研究上下文 Adapter 選型閘門

**狀態：** 開放評估；尚未選定候選方案  
**日期：** 2026-10-09  
**權威環境：** `172.16.9.166`

## 1. 目的與決策範圍

本文件是 [台股研究上下文 SDD](2026-10-09-research-context-sdd.md) 完成後的選型閘門，供未來
UI、聊天介面、LLM 編排或工作流候選方案共同使用。它不批准任何平台、adapter、API、proxy、
祕密、部署或服務重啟。

候選方案只能呼叫已驗證的 `ResearchContextBuilder` 資料契約；不得要求核心套件為特定平台改變
請求、回應、citation 或 warning 語意。

## 2. 必要前置證據

每一候選方案必須在開始實作前提供下列可審核證據：

| 項目 | 最低證據 | 不符合時的結果 |
|---|---|---|
| 資料契約 | 對應 `ResearchContextRequest` 與 `ResearchContextResponse` 的 mapping | 拒絕選型 |
| 資料權威 | 證明重用既有 RAG 排序，且不建立第二份語料或向量索引 | 拒絕選型 |
| 存取邊界 | 證明平台不直連 MongoDB、Ollama、主機檔案系統或排程 | 拒絕選型 |
| 唯讀性 | API/工具清冊與測試，證明無 Mongo 寫入、交易或排程觸發能力 | 拒絕選型 |
| 網路 | 私網拓撲、來源 allowlist、TLS 與 upstream 限制設計 | 不得部署 |
| 身分與祕密 | 服務對服務身分、祕密保存與輪替方案；不得把祕密放入 Git 或 workflow | 不得部署 |
| 維運 | 監測欄位、備份、復原責任人與演練證據 | 不得部署 |
| 故障語意 | RAG/Mongo 故障對使用者呈現「研究上下文暫時不可用」的測試 | 不得部署 |

## 3. 評估程序

1. 登錄候選平台、版本、執行位置與負責人。
2. 以第 2 節逐項提交證據，不以口頭承諾取代。
3. 在隔離環境驗證正常、無資料、未授權與後端故障路徑。
4. 由維運與資料權威責任人審核後，另立平台專屬 SDD/TDD 計畫。
5. 只有該計畫全部驗收後，才能提議正式環境部署。

## 4. 本次結論

目前沒有登錄候選平台，故沒有核准的 adapter 或部署工作。`172.16.9.166` 維持既有服務與
loopback-only MongoDB/FastAPI 邊界；不得因此文件執行 `deploy.ps1`、`scripts/deploy.sh`、
服務重啟或安裝任何平台元件。
